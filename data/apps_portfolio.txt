uDOWNLOADER
A tool to download videos and audio from YouTube, Instagram, TikTok, Twitter, and other platforms. Features a modern graphical interface (GUI) and a command-line (CLI) mode for power users.
Technologies: Python, Bash, Git.
Available on GitHub and PyPI (installable via pip).

CONVERTISSEUR SALAIRE BENIN (Salary Converter Benin)
A web application to calculate net or gross salary in Benin according to the 2025 finance law. Provides a detailed breakdown of employee and employer contributions, taxes, and net take-home pay.
Technologies: Python, Flask, HTML, CSS.
Live application available for public use.

AUTOMATISATION: GOOGLE SHEETS + PYTHON
A tool and tutorial to automatically create and share Google Sheets data reports from any server using Python. Designed for teams that need automated daily or weekly reports.
Technologies: Python, Google Drive API, MongoDB, Automation (cron).
Accompanied by a blog article and GitHub repository.

iBOLA — AI-POWERED CHATBOT
